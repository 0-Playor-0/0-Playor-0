## Selected work

| Project | What it is |
|---|---|
| **[Traffic-RL](https://github.com/0-Playor-0/Traffic-RL)** | A Deep Q-Network agent trained from scratch in PyTorch to dodge traffic on a three-lane highway. The environment is a custom `pygame` game exposing a Gym-style `reset()` / `play_step(action)` interface — no RL library involved, the replay buffer and training loop are written by hand. |
| **[HealthHarbor](https://github.com/0-Playor-0/HealthHarbor)** | A Flask fitness tracker with real-time community chat over Socket.IO. Messages are piped through a custom toxicity-classification model before broadcast, so flagged content is censored live. Also tracks sleep, calories against a food database, and a points leaderboard. Built with a team for Codingal 2024. |
| **[Zelda, But (Partly) Multiplayer](https://github.com/0-Playor-0/Zelda-but-Multiplayer-Partly-)** | A top-down action-adventure in Pygame with a hand-rolled TCP co-op layer: live position sync between clients, server-authoritative monster health, and automatic fallback to single-player when no server is running. |
