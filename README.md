## Currently

- **Social network analysis research.** Detecting bots and coordinated inauthentic behaviour in online social networks, as part of a faculty research project.
- **Reinforcement learning from first principles.** Hand-written training loops and agents compared head to head (see `cargo-storm`).
- **Deep learning without the framework.** Autograd, quantization and distillation written in plain NumPy (see `ace-numpy-dl`).
- **Working toward Google Summer of Code 2028.** Learning to work inside large existing codebases: reading unfamiliar code, filing useful issues, shipping small patches before big ones.

## Selected work

| Project | What it is |
|---|---|
| **[Cargo Storm](https://github.com/0-Playor-0/cargo-storm)** | Connect 4 in a ship's hold where gravity shifts and every crate slides. DQN, PPO and SAC agents trained from scratch in PyTorch play it, ranked by a 28,000-game Elo tournament. |
| **[ACE-Net](https://github.com/0-Playor-0/ace-numpy-dl)** | A deep learning stack in pure NumPy: a `Tensor` with reverse-mode autograd, layers, optimizers, int8 post-training quantization with an integer-only inference engine, distribution-shift tooling and knowledge distillation. Tests enforce that no autodiff library, scipy or sklearn is used. |
| **[Mirrorbound](https://github.com/0-Playor-0/mirrorbound)** | A top-down roguelite whose companion learns to fight like you, and whose final boss turns that against you. Python/FastAPI simulation over WebSockets with a React + Phaser client, plus utility AI driven by an online-learned player model. Built in 3.5 days with a team of five. |
| **[WALL-E and EVE's Signal](https://github.com/0-Playor-0/walle-eve-signal)** · [▶ live demo](https://0-playor-0.github.io/walle-eve-signal/) | An autonomous search-and-rescue agent in a castle it has never seen. From one noisy distress call it has to explore, tell the target apart from decoys, manage its battery, and decide when a gamble is worth it. Includes a pixel-art replay viewer. |
| **[Similar Pieces](https://github.com/0-Playor-0/ashiana-similar-products)** · [▶ live](https://ashiana-recs-ui.onrender.com) | A cold-start "similar products" recommender for a handcrafted jewelry brand. It fuses image embeddings, LLM-grounded text descriptors and metadata, with weights the shopper can see and adjust. FastAPI backend. |
| **[CrowdPerception](https://github.com/0-Playor-0/CrowdPerception)** | The perception layer for crowd-crush early warning. YOLOv11 and OC-SORT tracking feed foot-point homography to ground-plane metres, fitted velocities and density heatmaps, all tested against hand counts on real footage. |
